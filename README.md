## Local preview

Open `index.html` in a browser. For the most accurate local test, run a static server from this folder, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

1. Create a GitHub repository, e.g. `alliance-ice-cubes`.
2. Upload the **contents of this folder** to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Open the GitHub Pages URL generated by GitHub.
5. The custom domain is already configured in the source as `www.allianceicecubes.co.ke`.

## SEO launch checklist

Before submitting the live site to Google:

1. Absolute canonical URLs now point to `https://www.allianceicecubes.co.ke/`.
2. A production `sitemap.xml` is included and points to the custom domain.
3. A `CNAME` file is included with `www.allianceicecubes.co.ke`.
4. `robots.txt` already points to the production sitemap.
5. Verify the domain in Google Search Console and submit the sitemap.
6. Inspect the pages in Search Console and validate the structured data.
7. Add a Google Business Profile using the real business information.
